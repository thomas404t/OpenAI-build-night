# Champaign Eats

A single-page guide to restaurants in Champaign–Urbana for college students, with three ranked lists (best tasting, most value, local favorites), a schematic map, search, price filters, and saved places.

## Run it

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

Picks are compiled from local roundups. Prices are rough, so check hours and menus before you go.
